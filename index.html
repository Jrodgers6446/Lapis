Lapis / Pattern Draft

Parametric latex cutting patterns, generated from body measurements rather than a fixed size. All math runs internally in centimeters; switch units any time without losing your numbers.

Body measurements

Measure over bare skin or very thin underwear, with a soft tape held level and not pulled tight -- a friend helping gets more accurate results than measuring yourself. This is standard practice across latex makers, not specific to this tool.

Latex-specific factors

Bright&Shiny (a real latex maker) uses 10–15% reduction as their production standard \u2014 a reasonable reference range if you're unsure what to set here.

Export

Real garment panels are wider than a home printer's usable page area, so expect 15-30+ tiled pages for a full garment -- this is normal for printed sewing patterns generally, not specific to this tool. A copy shop with large-format (plotter) printing can output the same pattern on far fewer physical sheets if you'd rather not tape dozens together.
